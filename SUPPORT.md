# Support

This project is community-supported and provided without an SLA.

## Get help

1. Check [Troubleshooting](docs/troubleshooting.md).
2. Confirm the issue against the latest supported tagged release.
3. For usage questions, open a [GitHub Discussion](https://github.com/x3nc0n/m365-copilot-governance-foundation/discussions) if enabled.
4. For reproducible defects, open a [GitHub issue](https://github.com/x3nc0n/m365-copilot-governance-foundation/issues) with the template output below.

Include:

- release tag and deployment path;
- Azure region and cloud, without tenant or subscription identifiers;
- sanitized validation result and error code;
- expected and observed behavior;
- exact local/static command used;
- whether the source is absent, unsupported, unlicensed, unauthorized, stale, or unhealthy.

Never attach tokens, identities, tenant IDs, customer exports, prompts, responses, or unredacted support bundles.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not public support channels. Licensing, billing, preview availability, and Microsoft service incidents should be handled through the customer's Microsoft or GitHub support agreement.
